2026-04-27 - Wi-Fi stock source instrumentation plan
====================================================

Goal
----
Use the locally buildable stock kernel source as an editable oracle for
the remaining RTL8188EUS enumeration failure.  ROCKNIX now matches the
obvious stock-visible power, clock, regulator, and DWC2 host settings,
but still never sees USB device 0bda:8179.  The next step is to identify
the exact stock transition that makes the DWC2 host see a downstream
connect.

Known baseline
--------------
Stock v1.1.3:

    - boots and Wi-Fi scans
    - enumerates RTL8188EUS as USB 0bda:8179
    - uses DWC2 at ff300000
    - loads vendor 8188eu/r8188eu after USB enumeration

ROCKNIX:

    - vcc_wifi is enabled at 3300mV
    - otg_switch/boost is enabled at 5000mV
    - GPIO115 panel enable is high after panel prepare
    - DWC2 uses host mode and dummy USB supplies
    - DWC2 host-only config was tested
    - delayed DWC2 rebind was tested
    - still only sees the DWC2 root hub

Decision
--------
Stop using broad ROCKNIX image guesses as the primary method.  Modify the
stock source in small, reversible instrumentation patches.  Each stock
image must first confirm Wi-Fi still works, then the captured logs become
the source of truth for the next ROCKNIX change.

Instrumentation targets
-----------------------
First stock source pass:

    1. Instrument the source of:

           Rockchip WiFi SYS interface

       Found at:

           original-sources/extpackage/linux-kernel-rppocket/drivers/net/wireless/rockchip_wlan/wifi_sys/rkwifi_sys_iface.c

       This file prints:

           Rockchip WiFi SYS interface (V1.00) ...

       Log which init path it selects, the return values from each driver
       init call, and every call into rockchip_wifi_power().

    2. Instrument stock DWC2 host start and root-hub/port status:

           - before host start
           - after port power
           - after reset
           - when connect status changes
           - before usb 1-1 enumeration

       Log key register names and values, not large dumps.

    3. Instrument Rockchip USB2 PHY power/suspend path:

           - PHY power-on
           - suspend/resume writes
           - ID/VBUS/extcon decisions
           - reset/deassert calls

    4. Keep stock instrumentation conservative:

           - no MMIO writes
           - no broad devmem loops in boot hooks
           - printk-style kernel logs are preferred over userspace devmem
           - confirm stock Wi-Fi scan still works before trusting logs

Search for similar RTL8188EUS + YJ33 configurations:

    Local ROCKNIX search:

        RTL8188EUS, and a discrete YJ33/SGM2019-style Wi-Fi 3.3V regulator.
        The closest ROCKNIX patterns are SDIO Wi-Fi pwrseq nodes, for example

        mmc-pwrseq-simple, vcc_wifi, and a Wi-Fi enable/reset GPIO, but they
        do not describe a USB RTL8188EUS module behind a separate YJ33 rail.

Decision 2026-05-01: stop stock GPIO perturbations
--------------------------------------------------

    Perturbations 001-006 identify only one effective stock control:

        GPIO3_C3 / vcc5v_en_gpio controls the 5V input side.
