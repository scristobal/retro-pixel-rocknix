001 - OVERVIEW
==============================================================

Goal
----
Port ROCKNIX (Rockchip-handheld distribution, JELOS lineage,
LibreELEC-derived) to the FunnyPlaying RetroPixel Pocket V2.  The
existing AmberELEC-derived port at github.com/scristobal/RetroPixel_Pocket
is dead upstream, depends on a 7 GB external 'extpackage.tar.gz' the
author published on MEGA, and ships with a custom out-of-tree kernel.

ROCKNIX is actively maintained, mainline-friendly, and already supports
several RK3326 cousins of this device (Anbernic RG351M/V, Powkiddy
RGB10, Hardkernel ODROID-GO 2/3, etc.), so it is the right base.

Scope
-----
A ROCKNIX port for one specific device:

    SoC:      Rockchip RK3326 (quad Cortex-A35, Mali-G31)
    Body:     RetroPixel Pocket "V2" (the RK3326 revision; not the
              later RK3566 V3)
    Panel:    JDI LT031MDZ4000 (3.1" 720x720 IPS MIPI-DSI)
    Audio:    rk817 codec + NS4150 external amp on HP outputs
    Battery:  3000 mAh, no current-sense resistor, no rumble
    Wi-Fi:    Realtek RTL8188EUS (USB)

The hardware is essentially an Anbernic RG351M clone with the panel,
battery and rumble-motor specs changed.  The closest mainline reference
is rk3326-anbernic-rg351m.dts, which our DTS extends.

Status (snapshot)
-----------------
What works:

    - Boots from cold to EmulationStation
    - Display (correct rotation, correct backlight)
    - Audio out (speaker via NS4150)
    - All 12 standard buttons (D-pad, ABXY, L/R, SELECT, START)
    - SD card detection and storage resize
    - Game Boy emulator picks up ROMs dropped onto SD via pre.sh

What is broken / unfinished:

    - Volume and brightness rockers are mismapped (see 011-rocker-mystery.txt)
    - Wi-Fi: RTL8188EUS module not yet built into the image
    - Power slider behaviour beyond pwrkey not investigated
    - LED states / battery LED behaviour not verified
